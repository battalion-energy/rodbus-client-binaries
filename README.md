# rodbus-client

Prebuilt static Linux binaries for
[`rodbus-client`](https://github.com/stepfunc/rodbus).

Each GitHub Release includes:

- `x86_64-unknown-linux-musl`
- `aarch64-unknown-linux-musl`
- `SHA256SUMS`

This repository checks the latest stable upstream release weekly and publishes
it when needed. It also checks on pushes to `main`.
